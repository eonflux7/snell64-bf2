# Renderer: shader contract versions

Part of [the renderer as built](README.md). What the shaders may rely on now is in
[contract.md](contract.md); this is what each version of the contract added, in order. Raise
`RA_CONTRACT_VERSION` (`RendDX9Base.h`) in the change that alters what the shaders may rely on, add
its row here and update the current tables in [contract.md](contract.md) (`tools/docs.py check`
compares the last row with the define). Rows are history: a later row may replace part of an
earlier one, and says so.
